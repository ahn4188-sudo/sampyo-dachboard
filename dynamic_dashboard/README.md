# 동적 오피넷 대시보드

`html_dashboard.html`은 기존 정적 파일로 유지하고, 이 폴더는 최신 오피넷 자료를 서버에서 불러오는 별도 대시보드입니다.

## 설치

Python 3.10 이상이면 별도 패키지 설치가 필요하지 않습니다. 상위 폴더의 `.env`에 다음 값이 있어야 합니다.

```text
opinet_api_key=오피넷_API_키
```

## 실행

프로젝트 상위 폴더에서 실행합니다.

```powershell
python dynamic_dashboard/server.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 포트를 바꾸려면 다음처럼 실행합니다.

```powershell
$env:OPINET_PORT=8080
python dynamic_dashboard/server.py
```

## 자동 갱신과 캐시

- 한국시간 기준 오늘 날짜의 캐시가 있으면 API를 다시 호출하지 않습니다.
- 오늘 캐시가 없을 때만 오피넷 API에서 최근 7일·직전 7일 자료를 수집합니다.
- 캐시는 `dynamic_dashboard/cache/data_YYYY-MM-DD.json`으로 저장되어 서버를 재시작해도 유지됩니다.
- 동시에 여러 사용자가 접속해도 서버 내부 잠금으로 수집은 한 번만 실행됩니다.
- 수집 중에는 이전 캐시를 사용하고, 수집 실패 후 10분 동안은 재시도하지 않습니다.
- 화면 상단에 자료 기준일과 정상·갱신 중·이전 자료 상태가 표시됩니다.

페이지 접속 시 엑셀 생성이나 이메일 발송은 실행하지 않습니다.
